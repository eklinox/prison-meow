# Prison Life Aimbot

Clean external aimbot with GUI for Prison Life.

## Features
- Silent Aim
- Smooth aiming
- FOV circle
- Team check
- Prediction
- Draggable GUI
- Toggle with RightShift

## How to use
1. Open your executor (Madium recommended)
2. Join Prison Life
3. Copy the content of `aimbot.lua`
4. Execute
5. Hold **Right Mouse Button** to aim
6. Press **RightShift** to show/hide the GUI

## Config (inside GUI)
- Enabled
- Team Check
- Silent Aim
- Show FOV
- FOV Size slider
- Smooth slider

## Notes
- Works on most modern executors that support `getrawmetatable` + `Drawing`
- If silent aim does not hit, the remote name may have changed — open an issue
